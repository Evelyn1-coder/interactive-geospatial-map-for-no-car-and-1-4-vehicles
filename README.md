# Interactive Maps of Household Vehicle Access

A geospatial visualization project for comparing household vehicle access across areas. The project provides separate map packages for households with no vehicle and households with one to four vehicles.

## Explore the maps

1. Download and extract [No-Car-main.zip](No-Car-main.zip) to explore the zero-vehicle view.
2. Download and extract [1-4_Vehicles-main.zip](1-4_Vehicles-main.zip) to explore the one-to-four-vehicle view.
3. Compare the same area across both views and check each map's legend and units when interpreting differences.

These views support questions about where access to a household vehicle varies and where further transportation analysis could be useful.
